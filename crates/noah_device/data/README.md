# Device room data

These files let the device room say where a connection goes without asking
anyone on the internet.

- `ipv4-country.bin.gz`, `ipv6-country.bin.gz`: address ranges to country
  codes, built by `script/build-ip-country-data` from the aggregated
  registry export in [ipverse/rir-ip](https://github.com/ipverse/rir-ip)
  (CC0 1.0, public domain). Each entry is a big-endian start address (4 or
  16 bytes) followed by one byte: the index into `countries.rs`, or 255 for
  addresses no registry has given out. An entry runs until the next one
  starts. Both files are gzip.
- `countries.rs`: the country codes in index order with an English name and
  a centroid, from
  [world-countries-centroids](https://github.com/gavinr/world-countries-centroids)
  (MIT), generated by the same script.
- `world-dots.txt`: land as `#` on a 144 by 72 grid of 2.5 degree cells,
  rasterized from Natural Earth's 110m land polygons (public domain). Row 0
  is the northernmost band; column 0 is the western edge at 180 degrees
  west.
