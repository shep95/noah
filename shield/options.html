noah shield

tunnel servers

The tunnel is an encrypted proxy the browser sends everything through. It fails closed: when the server does not answer, requests stop instead of slipping out on the normal connection. DNS is resolved by the server and WebRTC is held to proxied routes. It protects this browser, not the rest of the computer.

Add a server of your own

Any HTTPS proxy or SOCKS5 server works: one you rent, one a friend runs, or Tor on this computer. A plain http proxy across the internet is refused because everyone on the path could read it.

Vetted servers come from noah's signed feed (not fetched yet).

data protection

fingerprint and location

Timezone, language and coordinates follow the chosen location, so they agree with the tunnel's exit. A page reload picks changes up.

cookies, history and identity

Settings sync, end to end encrypted

Your settings travel through the browser's own sync as a blob only your passphrase opens. Set the same passphrase on each browser.

Permission history

shopping

Price lookups fetch the other stores' public search pages with no cookies and only the product's name. The shield never places an order; it fills the code box and presses apply.

recording watch

Other extensions in this browser

An extension with capture permissions and reach into every site can take a screenshot of every frame you see. Ones that were not installed from a store weigh more. Disabling is reversible here or in the browser's own extension page.

Programs outside the browser (screen recorders, remote access tools) are what noah's device room looks for.

about

Feeds are signed with noah's ed25519 release key and refused when the signature does not match, so the website alone cannot change what the shield does. The shield sends nothing about you anywhere: no accounts, no telemetry. Tracker rules are EasyPrivacy (GPLv3 / CC BY-SA 3.0). Source: github.com/shep95/noah.
