what gets optimized

png — lossless re-compression, all metadata stripped. jpg — re-encoded at 92% quality, visually identical for most images. gif — converted to webp, rename the file after download. svg — whitespace and comments removed. docx · xlsx · pptx · zip — each internal file re-compressed at maximum deflate level. pdf — metadata, thumbnails, and xmp removed. mp4 · mov — title, author, and encoder metadata zeroed. json · css · html — whitespace collapsed. video transcoding requires desktop software.
